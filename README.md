# Data Cleaning and Exploratory Analysis of Economic Indicators

## Project Overview
This project focuses on cleaning, structuring, and performing exploratory data analysis (EDA) on a dataset of economic and development indicators. The goal is to transform raw, messy data into a clean and analysis-ready format, then generate meaningful insights through descriptive statistics and visualizations.

This work reflects real-world data preparation tasks commonly performed in monitoring & evaluation and applied economics contexts.

## Objectives
- Clean and preprocess a real-world economic dataset
- Handle missing values, duplicates, and data type inconsistencies
- Perform exploratory data analysis
- Generate clear visualizations and summary insights

## Tools & Technologies
- Python
- pandas

- matplotlib
- seaborn

## Dataset
The dataset used contains economic and social indicators (example sources: World Bank, national statistics, or open development data).
